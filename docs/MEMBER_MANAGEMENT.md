# 멤버 관리

관리자는 멤버 화면의 관리 창에서 다른 멤버를 삭제할 수 있습니다. 삭제 버튼을 누른 뒤 접근 권한 해제 안내에서 한 번 더 확인합니다. 본인 계정은 삭제할 수 없으며, 일반 멤버와 회계 권한만 가진 계정에는 삭제 권한이 없습니다.

삭제는 모임의 멤버십 해제입니다. Google·카카오 인증 계정 자체를 삭제하지 않습니다. 멤버 문서에 `removedAt`, `removedBy`를 기록하고 상태를 `rejected`, 권한을 `member`, 투표 생성 권한을 `false`로 바꿉니다. 이 기록은 Firebase의 기존 로그인 초기화가 삭제된 멤버를 새 가입자로 재생성하는 것을 막습니다. 삭제된 멤버는 명단과 승인 거절 목록에서 제외합니다.

연락처·거주 지역·생일은 같은 Firestore 트랜잭션에서 비웁니다. 문서 ID와 이름·이메일·등록일은 계정 식별과 기존 기록 연결을 위해 유지합니다. 사진·직책·공개 생일 정보는 멤버 문서에서 제거합니다. 게시글·투표·일정·회계 기록은 유지합니다. 진행 중 투표의 응답 수와 예정 일정의 참석 수에는 활성 멤버만 포함하며, 지난 기록은 그대로 열람할 수 있습니다.

Firestore 규칙은 관리자 권한, 본인 삭제 금지, 연락처 정리의 원자 처리를 검증합니다. 삭제된 사용자가 자신의 멤버십이나 연락처를 다시 쓰거나, 일반 승인 작업으로 삭제 상태를 제거할 수 없습니다. 실제 계정 삭제·재가입 정책이나 관리자 복구 화면은 별도 기능입니다.

검증: Firestore 규칙 테스트, 데모의 PC·모바일 삭제 확인, Auth·Firestore 에뮬레이터에서 실제 로그인 계정의 삭제 및 재로그인 후 권한 차단을 확인했습니다. 운영 멤버 삭제는 실행하지 않았습니다.
