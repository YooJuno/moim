# 카카오뱅크 거래내역 가져오기

관리자 또는 회계 담당은 **회계 장부 → 엑셀 가져오기**에서 카카오뱅크 원본 `.xlsx`와 파일 비밀번호를 입력합니다. 암호가 없는 파일은 비밀번호를 비워 둡니다. 파일을 확인한 뒤 거래 목록·새 내역·중복·추가 수입과 지출을 검토하고 **반영**을 누릅니다.

암호 해제와 해석은 브라우저의 별도 Worker에서 처리합니다. 원본 파일과 비밀번호는 서버·브라우저 저장소·오류 로그에 저장하지 않습니다. 저장 요청에는 확인한 거래내역만 포함됩니다. 잘못된 비밀번호, 지원하지 않는 형식, 불가능한 날짜, 맞지 않는 잔액, 구분할 수 없는 중복 원본은 반영 전에 중단합니다. 원본의 내용과 비고를 유지하며, 이름만 있는 거래는 회비로 추측하지 않습니다.

같은 계좌의 거래 일시·입출금 구분·금액·거래 후 잔액으로 거래 ID를 만듭니다. 파일명과 조회 기간이 달라져도 같은 거래는 제외됩니다. 이전에 별도 작업으로 반영한 `bank-…` 내역은 원본 파일·행 번호 또는 날짜·시간·금액·내용을 대조합니다. 기존 분류·비고·영수증은 덮어쓰지 않으며, 수기로 작성한 내역을 임의로 중복 취급하지 않습니다.

파일은 5MB 이하, 1회 최대 400건을 지원합니다. 더 긴 기간은 파일을 나눠 가져옵니다. 새로운 거래는 한 Firestore 트랜잭션으로 저장하고 저장 직전에 같은 거래가 존재하는지 다시 확인합니다. 기존 회계 내역을 삭제하거나 엑셀을 사이트의 장부 대신 통째로 교체하지 않습니다.

실시간 은행 연동은 포함하지 않습니다. 파일 합계의 마지막 거래 후 잔액은 해당 파일의 값이며, 일부 기간만 가져온 사이트 장부의 현재 잔액과 다를 수 있습니다.
