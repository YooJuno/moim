# 톡캘린더 연결과 검수

2026-11-01 기준 카카오 로그인은 운영 중이며, 톡캘린더는 지정된 기존 Google 계정의 연결 테스트만 허용합니다. 테스트 계정 목록은 Cloudflare Secret으로 관리합니다. 일반 멤버에게는 캘린더 버튼을 표시하지 않고 서버에서도 요청을 거절합니다.

## 카카오 콘솔

1. 기존 `moim` 앱에서 **카카오 로그인 → 동의항목**을 엽니다.
2. **톡캘린더 및 일정 생성, 조회, 편집/삭제(`talk_calendar`)**를 선택합니다.
3. **이용 중 동의**로 설정합니다. 선택 동의에 `API 검수 필요`가 표시되는 단계에서도 이용 중 동의로 연결 테스트를 진행할 수 있습니다.
4. 동의 목적은 `참여하는 모임 일정을 톡캘린더에 추가하고 변경사항을 반영`으로 입력하고 저장합니다.

일반 로그인과 내 정보의 계정 연결에는 캘린더 권한을 함께 요청하지 않습니다. 일정의 **캘린더 연결**을 누를 때만 인증된 현재 계정으로 `talk_calendar` 동의를 요청합니다.

## 본인 계정에서 테스트

1. 사이트에 기존 **Google 계정으로 로그인**합니다.
2. **모임 캘린더 → 확정된 일정 → 참여해요**를 선택합니다.
3. **카카오 캘린더 → 캘린더 연결**을 누르고, 이 개발자 앱의 오너 계정으로 카카오 동의를 진행합니다.
4. 동의 후 원래 일정의 캘린더 창으로 돌아옵니다. **내 캘린더에 반영**을 눌러 실제 일정을 추가합니다.
5. 톡캘린더에서 제목, 날짜, 시작·종료 시간과 장소를 확인합니다. 사이트에서 같은 내용을 다시 반영해도 새 일정을 중복으로 만들지 않습니다. 변경된 내용은 저장된 외부 일정 ID로 갱신합니다.

동의 완료만으로 외부 일정을 생성하지 않습니다. 참가자가 자기 캘린더에 반영하는 범위입니다. 이 절차를 다른 Google 계정에 카카오 계정을 연결하는 용도로 사용하지 않습니다.

## 일반 멤버에게 공개

검수 전에는 카카오 개발자 앱의 멤버만 톡캘린더 API를 사용할 수 있습니다. 본인 계정에서 정상 동작을 확인한 뒤 **앱 → 추가 기능 신청**에서 톡캘린더 사용 권한을 신청합니다. 서비스의 모든 사용자에게 제공하려면 카카오의 사용 권한 승인이 필요합니다.

사용 목적 설명 예시:

> 승인된 모임 참석자가 확정된 일정의 제목, 날짜, 시작·종료 시간과 장소를 본인의 톡캘린더에 추가하고 변경사항을 반영할 수 있도록 제공합니다. 사용자가 일정에서 캘린더 연결과 반영 버튼을 눌렀을 때만 처리합니다.

검수 화면에는 계정 연결, 톡캘린더 동의, 일정 반영과 결과를 보여줍니다. 실제 사용자 개인정보가 포함된 화면은 제출 자료에서 가립니다.

## 운영 설정

- `KAKAO_CALENDAR_ENABLED=true`: 캘린더 기능 사용
- `KAKAO_CALENDAR_TEST_ONLY=true`: 검수 전 테스트 제한. 테스트 계정 목록이 없으면 아무도 사용할 수 없습니다.
- `KAKAO_CALENDAR_TEST_UIDS`: 허용할 Firebase UID를 쉼표로 구분한 Worker Secret. 공개 설정과 레포에 포함하지 않습니다.
- `/account/providers`의 `calendar.available`: 현재 계정이 테스트/운영 범위에 해당하는지 여부
- `/account/providers`의 `calendar.kakao`: 현재 계정의 사용 범위, 저장된 토큰과 실제 `talk_calendar` 동의 내역을 함께 확인한 연결 상태

검수 승인 확인 후 `KAKAO_CALENDAR_TEST_ONLY=false`로 바꾸고 `KAKAO_CALENDAR_TEST_UIDS` Secret을 삭제해 일반 멤버에게 공개합니다. 이 설정을 바꾸기 전에는 테스트 제한을 유지합니다.
