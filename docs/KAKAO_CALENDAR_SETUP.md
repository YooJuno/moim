# 톡캘린더 자동 반영과 검수

2026-11-01 기준 카카오 로그인은 운영 중이며, 톡캘린더는 지정된 기존 Google 계정의 연결 테스트만 허용합니다. 테스트 계정 목록은 Cloudflare Secret으로 관리합니다. 일반 멤버에게는 연결 버튼을 표시하지 않고 서버에서도 요청을 거절합니다.

## 연결 방법

1. 기존 **Google 계정으로 로그인**합니다.
2. **내 정보 → 계정 → 카카오 → 연결**을 누르면 계정 연결과 캘린더 동의를 한 번에 진행합니다. 이미 카카오 로그인만 연결했다면 같은 항목의 **참여 일정 자동 반영**을 켭니다. 확정된 일정에서 **참여해요 → 카카오 캘린더 → 자동 반영 연결**로 시작해도 됩니다.
3. 카카오 개발자 앱의 오너 계정으로 로그인하고 톡캘린더 이용에 동의합니다. 계정 이름이나 이메일로 사용자를 합치지 않고 기존 Firebase 계정에 연결합니다.
4. 이후 일정 확정, 시간·장소 수정, 참석 등록을 자동 반영합니다. 일정에서 시작했다면 해당 일정도 연결 직후 반영합니다.
5. **불참**으로 바꾸거나 모임 일정이 삭제되면 앱이 등록한 톡캘린더 일정도 삭제합니다. **내 정보 → 계정 → 카카오 → 참여 일정 자동 반영**을 꺼서 이후 자동 처리를 끌 수 있습니다. 연결 해제 시 이미 등록한 외부 일정을 일괄 삭제하지는 않습니다.

로그인 화면의 일반 카카오 로그인은 캘린더 권한이나 자동 반영 설정을 변경하지 않습니다. 내 정보에서 캘린더 사용이 허용된 활성 멤버에게는 카카오 연결 버튼에 로그인·캘린더 자동 반영 범위를 표시합니다. 사용자가 이 연결이나 자동 반영 스위치를 직접 선택했을 때만 `talk_calendar` 권한과 자동 반영 설정을 저장합니다. 최초 연결 후에는 일정마다 별도의 추가 버튼을 누를 필요가 없습니다.

## 반영 대상과 처리

- 승인된 활성 멤버 중 톡캘린더 사용에 동의하고 **자동 반영을 켠 사람**이 대상입니다.
- 명시적으로 참석 등록했거나, 일정 투표에서 확정된 **시작부터 종료까지 모든 시간**을 선택한 사람을 포함합니다. 명시적 불참 응답을 우선합니다. 이미 등록된 참석자의 일정은 이후 날짜·시간이 바뀌어도 같은 외부 일정 ID로 갱신합니다.
- 서버에서 대상자의 계정 활성 상태와 권한을 재확인합니다. 비활성·삭제 계정, 미동의 계정에는 전송하지 않습니다.
- 일정 저장과 같은 Firestore 원자 작업에 처리 요청을 저장합니다. 브라우저는 즉시 처리를 시도하고, 창을 닫거나 요청이 끊기면 Cloudflare의 매분 예약 작업이 이어갑니다. 외부 API 응답과 대기열에 따라 반영이 지연될 수 있습니다.
- 한 번에 최대 6명을 처리해 Workers Free의 외부 요청 제한 안에서 작업을 나눕니다. 매분 예약 작업은 Firebase 유료 기능을 사용하지 않습니다.
- 같은 내용은 다시 보내지 않고, 수정 시 저장한 외부 일정 ID를 갱신합니다. 생성 응답이 유실돼 실제 생성 여부가 불명확하면 중복 생성을 막기 위해 자동 재생성하지 않고 확인이 필요한 실패로 기록합니다.

공식 일반 일정 API에는 비공개 참석자 일괄 초대 파라미터가 없습니다. 각자가 연결한 본인 톡캘린더에 같은 모임 일정을 자동으로 등록하는 방식입니다. 카카오톡 채팅 메시지 발송과는 별개입니다.

## 카카오 콘솔

1. 기존 `moim` 앱에서 **카카오 로그인 → 동의항목**을 엽니다.
2. **톡캘린더 및 일정 생성, 조회, 편집/삭제(`talk_calendar`)**를 선택합니다.
3. **이용 중 동의**로 설정합니다. 선택 동의에 `API 검수 필요`가 표시되는 단계에서도 이용 중 동의로 연결 테스트를 진행할 수 있습니다.
4. 동의 목적을 `참여하는 모임 일정을 톡캘린더에 추가하고 변경사항을 반영`으로 입력하고 저장합니다.

## 일반 멤버에게 공개

검수 전에는 카카오 개발자 앱의 멤버만 톡캘린더 API를 사용할 수 있습니다. 본인 계정에서 정상 동작을 확인한 뒤 **앱 → 추가 기능 신청**에서 톡캘린더 사용 권한을 신청합니다. 서비스의 모든 사용자에게 제공하려면 카카오의 사용 권한 승인이 필요합니다.

사용 목적 설명 예시:

> 사용자가 기존 모임 계정에 카카오 계정을 연결하고 톡캘린더 자동 반영에 동의하면, 참석하는 모임의 확정 일정과 변경사항을 본인의 톡캘린더에 등록·수정합니다. 불참 등록과 일정 삭제 시 앱이 등록한 일정을 삭제하며, 내 정보에서 자동 반영을 해제할 수 있습니다.

검수 자료에 계정 연결, 이용 중 동의, 자동 반영 연결·해제, 일정 확정·변경 결과를 포함합니다. 실제 사용자 개인정보는 가립니다. 코드·모의 API·에뮬레이터 검증과 별도로 실제 오너 계정의 OAuth 동의 및 톡캘린더 반영은 사용자가 확인해야 합니다.

## 운영 설정

- `KAKAO_CALENDAR_ENABLED=true`: 캘린더 기능 사용
- `KAKAO_CALENDAR_TEST_ONLY=true`: 검수 전 테스트 제한. 테스트 계정 목록이 없으면 모두 차단합니다.
- `KAKAO_CALENDAR_TEST_UIDS`: 허용 Firebase UID를 쉼표로 구분한 Worker Secret. 공개 설정과 레포에 포함하지 않습니다.
- `/account/providers`의 `calendar.available`: 현재 계정의 테스트/운영 범위 허용 여부
- `calendar.kakao`: 저장된 토큰과 실제 `talk_calendar` 동의 내역을 확인한 연결 상태
- `calendar.automatic`: 사용자가 선택한 자동 반영 설정

검수 승인 후 `KAKAO_CALENDAR_TEST_ONLY=false`로 바꾸고 `KAKAO_CALENDAR_TEST_UIDS` Secret을 삭제해 공개합니다. 승인 확인 전에는 제한을 유지합니다.
